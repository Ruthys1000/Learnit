# מחולל לומדות דיגיטליות

כלי פשוט שהופך את **חומרי הלמידה שכבר יש לכם** ללומדה דיגיטלית אינטראקטיבית — עם עמודים, שאלות, מילון מונחים, תמונות וסרטונים — ומייצא **אתר עצמאי** או **חבילת SCORM** להעלאה ל-Moodle ולמערכות LMS.

הקובץ `textbook_generator.html` הוא הכלי. פותחים אותו בדפדפן — זהו, אין התקנה. הכל רץ מקומית, והתוצר עובד גם ללא אינטרנט.

## איך עובדים איתו — שלב אחר שלב

1. **מקבלים את התוכן מה-AI.** בכרטיס הפתיחה לוחצים **"העתק פרומפט ל-AI"**, מדביקים ב-ChatGPT או Claude. ה-AI יבקש מכם את חומרי הלמידה שלכם (סיכומים, מאמרים, מצגות, מקורות) — מדביקים או מצרפים — ישאל כמה שאלות קצרות (קהל יעד, אורך, טון), ואז יכתוב את הלומדה בפורמט הנדרש. הלומדה נבנית **מהחומר שלכם** בלבד.
2. **מדביקים ב"מקור".** מעתיקים את כל הטקסט שקיבלתם ומדביקים בלשונית **"מקור"**.
3. **צופים ומתקנים.** מפעילים **"תצוגה מקדימה"** כדי לראות את הלומדה בדיוק כפי שהלומד/ת יראה. אם מופיעות הערות צהובות (למשל שאלה בלי תשובה מסומנת) — לוחצים עליהן כדי לקפוץ למקום בטקסט ולתקן.
4. **מוסיפים מדיה.** בסרגל התצוגה המקדימה לוחצים **"הוסף מדיה"**, בוחרים תמונה או סרטון, ובוחרים **היכן בעמוד** למקם אותו. הקובץ מופיע מיד ונכלל אוטומטית בייצוא.
5. **מעצבים מיתוג.** בלשונית **"מיתוג"** קובעים לוגו וצבע מותג. תחת "הגדרות מתקדמות" אפשר גם פונט, גודל טקסט, רקע וכותרת משנה.
6. **מסדרים עמודים.** בלשונית **"מבנה"** אפשר להוסיף, לשנות שם, לשכפל, למחוק ולסדר מחדש עמודים.
7. **מייצאים.** לוחצים **"ייצוא"** ובוחרים:
   - **אתר עצמאי** — קובץ HTML יחיד שרץ בכל דפדפן.
   - **חבילת SCORM** — להעלאה ל-Moodle ולמערכות LMS (עם ציון והתקדמות).

## טוב לדעת

- **הטקסט הוא מקור האמת.** כל מה שרואים בלומדה נקבע מהטקסט בלשונית "מקור"; כל עריכה מתעדכנת מיד בתצוגה.
- **שמירת עותק.** כפתור **"שמור טקסט"** מוריד את הטקסט למחשב כדי שתוכלו לחזור אליו או להמשיך בהמשך.
- **עובד אופליין.** התוצר המיוצא אינו טוען פונטים או קבצים מהאינטרנט — מתאים לאירוח סגור ול-Moodle.
